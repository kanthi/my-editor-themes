# Antigravity IDE

Antigravity IDE is VS Code–compatible. It does not get a separate theme JSON.

Use [../vscode](../vscode) — same `package.json` theme contribution.

## Install

```sh
ln -sfn "$HOME/Workspace/Repos/my-editor-themes/ports/vscode" \
  "$HOME/.antigravity-ide/extensions/kanthi.midnight-aurora-subtle"
```

Reload the window (`Developer: Reload Window`), then **Preferences: Color Theme** and pick a Midnight Aurora variant (Subtle, Void, Dusk, Ember, Tide).
