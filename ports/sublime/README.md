# Sublime Text

Sublime Text color schemes for the Midnight Aurora family, plus the original Aurora UI theme.

| File | Role |
|------|------|
| `Midnight Aurora Subtle.sublime-color-scheme` | Original syntax colors |
| `Midnight Aurora Void.sublime-color-scheme` | Near-black |
| `Midnight Aurora Dusk.sublime-color-scheme` | Lifted navy |
| `Midnight Aurora Ember.sublime-color-scheme` | Warm dark |
| `Midnight Aurora Tide.sublime-color-scheme` | Cool blue-black |
| `Midnight Aurora Haze.sublime-color-scheme` | Warm stone, lowest contrast |
| `Midnight Aurora.sublime-theme` | Subtle UI chrome (base) |
| `Midnight Aurora Subtle.sublime-theme` | Alias of the base UI theme |
| `Midnight Aurora Void.sublime-theme` | Void UI chrome |
| `Midnight Aurora Dusk.sublime-theme` | Dusk UI chrome |
| `Midnight Aurora Ember.sublime-theme` | Ember UI chrome |
| `Midnight Aurora Tide.sublime-theme` | Tide UI chrome |
| `Midnight Aurora Haze.sublime-theme` | Haze UI chrome |

Pair each color scheme with the UI theme of the same name. The live setup may still use a different UI theme (for example Zed Dark).

## Install

```sh
cp -p Midnight\ Aurora*.sublime-color-scheme \
  "$HOME/Library/Application Support/Sublime Text/Packages/User/"
cp -p Midnight\ Aurora*.sublime-theme \
  "$HOME/Library/Application Support/Sublime Text/Packages/User/"
```

Then set `color_scheme` and `theme` to the matching Midnight Aurora files.
