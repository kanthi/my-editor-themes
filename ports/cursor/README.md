# Cursor

Cursor loads VS Code themes. It does not get a separate theme JSON.

Use [../vscode](../vscode).

## Install

```sh
ln -sfn "$HOME/Workspace/Repos/my-editor-themes/ports/vscode" \
  "$HOME/.cursor/extensions/kanthi.midnight-aurora-subtle"
```

Reload the window, then set Color Theme to a Midnight Aurora variant (Subtle, Void, Dusk, Ember, Tide).
